# Dvd Screen Saver
Probably the stupidest project you will ever see, a Dvd screen saver written in python using pygame. This project is pretty simple as far as coding goes, and has options for the user to do whatever with. There are a couple bugs to work out but those won't take long.

# Contributions
The latest python version that pygame supports is 3.12.4, thus that is the version I am using to write this. Make sure to fork this repository and push your commits to your fork, create a pull request to merge your edits with my repository.
